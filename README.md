# 图形面体积计算器 (GeometryCalc)

图形面体积计算器是一款基于 Qt 6 开发的轻量级桌面工具，用于快速计算常见图形的面积和体积。它无需记忆公式，通过直观的 GUI 界面即可完成计算，属于"几何学习"的实用小助手。

本项目基于 Qt 6 的图形面体积计算工具，支持 `Windows` 和 `Android` 平台。

## 功能
- 下拉框选择 10 种常见图形（正方形、长方形、平行四边形、梯形、圆形、正方体、长方体、圆柱体、圆锥体、球体）
- 双输入模式：支持物理键盘直接打字和底部虚拟数字键盘点击输入
- 点击参数标签切换激活状态，高亮反馈当前输入参数
- 计算结果附带详细公式展示
- 一键全部清空，重新选择图形

## 编译
1. 安装 Qt 6.11.2（勾选 MinGW 64-bit）
2. 打开 `GeometryCalc.pro`
3. 构建 → 运行

## 声明
本程序仅为一个学习辅助工具，计算结果仅供参考
